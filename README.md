## 防御峰值买多大：按会被打多大分三档

先估一个量级，再去对套餐。

**几十 G 以内**：宿舍服、小群服、只在内网或熟人圈传播的私服。这个量级不需要专门买高防机型，游戏云 NAT 版自带的 150G 共享防御就覆盖住了。E5 2666v3 固定 30 元/月、动态 15 元/月起，是成本最低的起点；想开模组服就加到 Ryzen 5900X 的 45 元。

**100G 到 200G**：已经对外公开、有买量、被同行盯上过。这个档位开始要求独享清洗，重庆 100G 加购独立 IP 后约 115 元/月，襄阳 200G 加购高防 IP 后约 88 元/月（58 + 30），都比直接买 BGP 机型便宜。襄阳的 200G 在价格上是最甜的一档。

**400G**：被反复针对，或者一个 IP 下挂多个服、多个业务。十堰 400G 两条：2核2G / 10M / 不限流量 60 元/月，8核16G / 20M / 不限流量 170 元/月。前者适合只做转发或小体量服，后者才扛得住多人同时在线的整合包。

买大了浪费钱这件事在高防上格外明显。一个只有十几个人玩的私服，买 400G 除了把月付从 45 元抬到 60 元，实际防护体验没有区别，因为攻击根本不会到这个量级。

## 共享防御和独享高防：150G 这个数字要拆开看

这是选错最多的一处。

游戏云的 NAT 模式写的是「自带 150G 共享防御」。共享的含义是：你和同一台宿主机上的人共用一个公网 IP，清洗资源是大家一起用的。好处是便宜，45 元一个月就能开服；代价是别人打这个 IP，你的服跟着抖，你被打也会波及同一 IP 上的其他人。宿舍私服完全无所谓，反正 IP 也不公开。

游戏云的独立 IP 模式是「独享 150G 京东云高防」。同一个 150G，独享意味着清洗资源只对你这个 IP 生效，别人被打不牵到你，你被打也不会牵连别人。对外公开、IP 会被人扫到的服，必须选这个。125 元/月起步，比 NAT 版贵 80 元，这 80 元买的是隔离。

RCS 高防云也是同样的逻辑。重庆那台 35 元的机器默认 NAT，10 个端口映射，适合做个人项目、小型社区；要正经对外提供服务，加购 80 元/月的 100G 高防 IP，总价 115 元，才算是真正独立的高防 IP。

很多人以为买了「150G 防御」就等于有 150G 的抗攻击能力，实际上共享 IP 下这个数字是所有租户分摊的，你无法控制隔壁在干什么。

## 带宽和流量：两个只写在脚注里的限制

**限流量机型用完会限速。** 重庆 2核4G 那台给的是 50M 带宽 + 每月 300GB 流量，用完限速到 5M。同价位还有一个「不限流量但带宽降到 20M」的版本。怎么选看业务形态：开服是持续小包高频，300GB 撑不了多久，选不限流量那版更稳；如果是间歇性使用的测试服，300GB 加 50M 峰值反而更划算。

**「200M 带宽」是峰值，不保障跑满。** 广州番禺那两台 120 元的机器标的是 200M 峰值带宽、不限流量，适合带宽突发型业务。开服属于持续稳定上行，指望它 24 小时跑满 200M 会失望。它的真正价值在于 BGP 多线，阿里和腾讯两条线路，三网访问都不用绕路，这是电信单线机型给不了的。

单线机房（重庆、襄阳、十堰）便宜，代价是联通、移动用户访问要绕。玩家三网混杂、又在意延迟，番禺那两台 120 元的 BGP 机型比 35 元的重庆贵三倍多，钱花在线路上。

## 游戏服吃单核，不吃核数

Minecraft 这类游戏服，主逻辑压在一个主线程上。核心多到 8 个、16 个，单核频率上不去，TPS 照样掉，玩家走两步回弹一步。

公开测评里，Ryzen 5900X 的 CPU-Z 单核在 568 分上下，UnixBench 单核 1480 分；i9 14900KF 在雨云论坛的一篇机型测评里 CPU-Z 单核跑到 907 分、UnixBench 单核 3672 分。这个差距开模组服、群组服时体感很明显。

所以游戏云的机型是 2 核 12G 这种形态，内存给足、核心给少、单核拉满。8 核 16G 的十堰机型跑分好看（UnixBench 多核 9611 分），但那是给需要并行处理多业务的场景准备的，纯开服买它属于花错钱。

反过来说，如果服里跑的是整合包 + 多个附属服务（面板、数据库、语音），核心数才开始有意义。判断标准很简单：卡的时候是 TPS 掉（单核问题），还是整机负载满（核心问题）。

## 常见问题

**开服当晚玩家卡在登录界面，CPU 和带宽都正常，是防御不够吗？**

大概率不是峰值不够，是登录端口被 CC 或 TCP 连接耗尽打住了。这类攻击流量不大，但连接数极多，传统按流量特征清洗的方式分不清恶意连接和真实玩家，触发清洗时容易连正常玩家一起掐掉。判断方法是看登录日志有没有海量异常连接请求。公开资料里没有雨云针对游戏登录口的具体清洗策略说明，这种情况建议先用 1 元试用开一台，把登录流程压一遍再决定。

**NAT 机能不能开公开服？**

技术上能，15 个端口转发对 Minecraft、泰拉瑞亚这类足够用。问题在共享 IP：你的服暴露在公网上，别人打这个 IP 你会跟着受影响。熟人服、白名单服、需要端口转发省钱的场景选 NAT；只要 IP 会被人扫到、会被人挂到论坛，就上独立 IP。

**1 元试用怎么用、能试几次？**

云服务器和游戏云都支持 1 元试用 1 天，每款限 1 次，部分高价产品试用价会高一些。用法就是花 1 块钱把机器拉起来，测延迟、测带宽、测防御，跑一圈再决定买不买。

**7 天无理由退款有什么限制？**

每个账号限 3 次。也就是说你有三次反悔机会，不是无限退。真要用这条兜底，就别在一个月里连着开三台又退三台。

**动态计费和固定计费选哪个？**

固定计费是一口价，动态计费按 CPU 实际占用浮动，闲置便宜、满载变贵。玩家集中在晚上的服，动态计费可能比固定便宜；24 小时有人的服，固定计费更可控。负载波动越大，动态计费越有优势。
